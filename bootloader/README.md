# Boot-chain research

This directory is for documentation and non-destructive analysis only.

The Moto G60 boot process must be understood before any device-specific kernel work can be considered. Record verified facts about firmware stages, boot image format, partition names, device-tree handling, verified boot, and recovery procedures.

**No bootloader replacement, unlock bypass, partition-writing script, or flashable image is provided here.** Do not experiment on a daily-use device. A kernel compiling successfully does not make its image safe to flash.
