# MotoDarwin 0.1.0-dev1 — Development Preview (Non-Bootable)

**Release type:** Pre-release  
**Tag:** `v0.1.0-dev1`  
**Status:** In development

## What's included

- A 1 MiB development placeholder asset for release packaging.
- Initial project and hardware research documentation.
- An early AARCH64 UEFI application prototype (built locally; emulator execution is not yet verified).

## Important limitations

- The attached `.img` is **not bootable**.
- It is not firmware, an installer, a boot image, or an operating system.
- It contains no bootloader, partition table, filesystem, or kernel.
- It has not been tested on physical hardware.
- No Moto G60 device compatibility is established.
- Do not flash or write this file to any device.

## Current focus

The next development milestone is safe emulator testing of the UEFI application, followed by reproducible build checks and continued hardware/driver feasibility research.

MotoDarwin is an independent Darwin/XNU research prototype. It is not an official Apple or Motorola product and does not provide iOS.
