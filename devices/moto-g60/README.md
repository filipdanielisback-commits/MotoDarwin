# Motorola Moto G60 (hanoip)

Device-specific research belongs here.

## Current state

No Moto G60-specific XNU platform code, boot image, or validated driver is provided by this repository.

## Required inventory

- Exact retail model and region
- Bootloader / firmware baseline
- Android build fingerprint
- Current kernel version and source provenance
- Device tree and board configuration
- Partition layout (document only; do not modify)
- SoC, PMIC, display panel, touch controller, audio codec, wireless chipset, sensors, and camera modules
- Recovery method and official firmware references

## Safety

Do not flash experimental images or overwrite boot-critical partitions. Keep all early work to read-only inspection, source analysis, and supported emulation. Any future device test requires a verified recovery path and independent review.
