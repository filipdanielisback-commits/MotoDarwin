# Test plans and evidence

Store reproducible test plans and summaries here. Avoid committing private logs, device identifiers, Wi-Fi credentials, account tokens, or other sensitive information.

## Minimum evidence record

- Test ID and date
- Device / emulator and exact variant
- Host environment and toolchain
- Source revision and patch set
- Steps performed
- Expected and observed result
- Relevant sanitized logs
- Pass / fail / blocked
- Reviewer and known limitations

Do not mark a subsystem "working" based only on compilation or a screenshot.
